# qa_python

В tests.py написаны тесты для класса BooksCollector:

- test_add_new_book_add_two_books проверяет, что после добавления 2 разных книг в пустую коллекцию словарь содержит 2 книги

- test_books_genre_is_empty проверяет, что первоначальный словарь books_genre пустой 

- test_genre_has_all_genres проверяет, что список genre содержит все доступные жанры

- test_add_new_book_length_0_and_41_not_added проверяет, что книги с названиями длиной 0 и 41 символ не добавляются в books_genre

- test_set_book_genre_valid_name_and_genre проверяет, что книге с валидным названием и жанром устанавливается соответствующий жанр 

- test_get_book_genre_book_without_genre проверяет, что при добавлении книги без установки жанра - при выводе жанра по имени получаем пустую строку

- test_get_book_genre_valid_name_returns_genre проверяет, что выводится корректный жанр по валидному имени добавленной книги

- test_get_books_with_specific_genre проверяет, что возвращается корректный список добавленных книг по указанному жанру

- test_get_books_genre проверяет корректный вывод словаря по добавленным книгам

- test_get_books_for_children проверяет, что возвращается корректный список книг по жанрам, доступным для детей (книги с возрастным рейтингом не выводятся)

- test_add_book_in_favorites проверяет, что книга, добавленная в избранное, находится в избранном

- test_delete_book_from_favorites проверяет, что книга, удаленная из избранного, не находится в избранном 

- test_get_list_of_favorites_books проверяет, что из двух книг, которые пытались добавить в избранное - добавляется и возвращается только та, которая есть в словаре
